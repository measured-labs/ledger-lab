1. 저장 모델 = **평범: 컬럼 UPDATE** — 사용자 잔액 컬럼 + 적립 건마다 남은 금액 컬럼 UPDATE + 간단한 이력 로그. README의 Insert-only 원장 + 적립 건별 상세는 '해법'이므로 기준선에 넣지 않는다(02의 흉내 PG 원장과 같은 이유 — 왜 필요한지 관측).
2. 기능 = 적립 · 사용 · 잔액 조회 · 사용 취소(부분) · 적립 취소 · 만료 배치 · 이력 조회. 모두 **동기 REST**(큐 · 비동기는 Q5 순서 역전 ADR에서).
3. 사용 차감 순서 = **만료 임박 순**(같으면 적립 순).
4. 사용 취소 환원 = **새 적립으로 되돌림**(원래 적립 건 · 유효기간은 사라진다 — Q3 · Q4 관측점).
5. 일부 사용된 적립 건의 적립 취소 = **남은 만큼만 소멸**(쓴 몫은 회수 못 함 — 이후 ADR에서 관측).

7. 기반 = **02와 같게**: PostgreSQL 16 + JPA + Flyway · repo docs 기록 · 브랜치 `feat/adr-000-baseline` · auto · blind/구현 워커 분리 · 송금(Q7 확장)은 기준선에서 제외.
8. stakes = **높음** · 명세는 02 마감 뒤.
